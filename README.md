## About

Fairy Fight is a 2D arcade game developed with Pygame. The game has 2 levels and each level ends with a timeout event. It can be played in coop (2 players). Score is saved in a SQLite3 database.

---

## To Play

- Player 1: Arrow keys to move, `P` to shoot  
- Player 2: WASD to move, `H` to shoot
